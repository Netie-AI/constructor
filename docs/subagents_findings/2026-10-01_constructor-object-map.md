# Object map

Keywords: constructor, object-map, merge, skin-state, synthetic, no-fetch, axe

Main idea: Clickable object map on the Constructor skin. Deterministic circle layout. Merge suggestions from name, key overlap, and shared source table. A merge is a proposal in netie.skin-state/1 and is never auto-applied. Certified stays a Cortex-only read. Seed is the synthetic orders fixture plus companion tables in object-map.js. Golden file locks the map.
